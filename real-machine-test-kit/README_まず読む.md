# Surfer GRD Converter v0.1.0 実機テストキット — まず読む

対象: Windows実機 (yo1PC-01) の QGIS で、Surfer GRD Converter v0.1.0 の
GUI確認を行うためのキットです。実施者は PC側の Claude (Claude Code /
Desktop) または Codex のどちらか一方で十分です。二重に実施しないで
ください (クレジット節約のため)。

## 和田さんが行うこと (これだけ)

1. このキットフォルダ一式を PC で開ける場所に置く
   (Drive同期フォルダ、または USB / ダウンロード経由でコピー)。
2. PC側 Claude / Codex を起動し、次の1行を渡す:

   「<このフォルダのパス> の README_まず読む.md と
    01_実機テスト指示書.md を読んで、実機テストを一括で実施し、
    報告を report フォルダに保存して」

3. 終わったら report フォルダの中身を Muse (ハブ側) に戻す
   (Driveに置くか、このチャットに上げる)。

## PC側AIが行うこと

- 01_実機テスト指示書.md の W01〜W09 を**1セッションで一括**実施する。
- 結果は 02_チェックリスト兼報告書.md をコピーして記入し、
  report/報告書.md として保存する。スクリーンショットは
  report/shots/ に置く。
- 失敗した項目は、その場で際限なくリトライしない。**リトライは1回まで**。
  2回目も失敗したら、エラーメッセージ全文と画面の状態を報告に記録して
  次の項目へ進む (04_クレジット節約策.md 参照)。
- プラグイン本体のコードは変更しない。GitHubへの公開、plugins.qgis.org
  への提出は行わない (このキットの範囲外)。

## サンプルの中身 (期待値の元)

- 5列 x 5行、値 0〜24、中央の1セルだけ Surferブランク値 1.70141e38
- X範囲・Y範囲とも 100〜150 相当 (GRDヘッダ上のノード範囲は 105〜145、
  GDALのセル中心は 105,115,125,135,145)
- つまり「正常な値が24個、ブランクが1個」が全項目共通の前提
